# Charity Finder App

## Descripción
Charity Finder es una aplicación web que utiliza la API de GlobalGiving para conectar a los usuarios con organizaciones benéficas de todo el mundo. Permite realizar búsquedas personalizadas por nombre, país de origen, países atendidos y temáticas filantrópicas, ofreciendo una experiencia clara y pulida para incentivar el apoyo a causas sociales.

## User Stories (Requisitos Base)
- Como usuario, quiero ver un encabezado con el nombre de la aplicación.
- Como usuario, quiero ver un resumen del propósito de la app en formato 'splash page'.
- Como usuario, quiero un área de búsqueda con desplegables para filtrar por nombre de organización, país de origen y países que atiende.
- Como usuario, quiero un botón de 'Buscar' para consultar la API y mostrar los resultados.
- Como usuario, quiero ver tarjetas de resultados con ID, Nombre, Dirección y Logo de la organización.
- Como usuario, quiero hacer clic en el logo para abrir el sitio web oficial de la organización en una pestaña nueva.
- Como usuario, quiero un pie de página con enlaces e íconos hacia mi GitHub y redes sociales.
