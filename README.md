# charity-finder-app
Justificación de la necesidad: Elegí Charity Finder porque resuelve la necesidad de conectar a donantes con causas sociales globales mediante una interfaz clara y cuidada, permitiendo realizar búsquedas filtradas (por nombre, país de origen, países servidos y temas) para reducir la tasa de abandono del sitio y maximizar el impacto social.
